# Beaconed Biter Spawner

Lets beacons affect the Captured Biter Spawner, and optionally adds module slots to it.

## Settings (startup)

- **Enable speed effect** — speed beacons affect the Captured Biter Spawner; also allows speed modules.
- **Enable productivity effect** — productivity beacons affect the Captured Biter Spawner; also allows productivity modules and enables productivity on the `biter-egg` recipe (alternative biter-egg recipes from other mods are affected too).
- **Enable quality effect** — quality beacons affect the Captured Biter Spawner; also allows quality modules. Note: only one quality type can be in the output — remove biter eggs or a batch may be lost if it's not the same quality.
- **Enable pollution effect** — pollution beacons affect the Captured Biter Spawner; also allows efficiency modules (pollution effect only, which reduces the spawner's pollution absorption).
- **Enable consumption effect** — consumption beacons affect the Captured Biter Spawner; also allows efficiency modules (consumption effect only).
- **Add a number of module slots** — adds this many module slots (0–1000) to the Captured Biter Spawner; module categories are enabled to match the effect toggles above.

All effect toggles default to off and the module slot count defaults to 0 (vanilla behaviour).
